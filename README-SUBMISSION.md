# EU Pay QA Engineer Assessment - Submission Summary

For this technical assessment, I took a risk-based, test-first approach to systematically audit EU Pay's core payment and merchant APIs. First, I manually investigated and reproduced all 7 intentional bugs across authentication, payments, webhooks, table orders, and e-invoicing using Postman and curl to observe actual runtime behavior and analyze business impacts. Next, I implemented minimal, production-grade fixes that adhered strictly to existing API contracts, introducing proper data parsing, AML transaction ceilings, cryptographic signature checks, idempotency, and concurrency guards. Finally, I authored 15 automated regression tests using Node.js's native test runner (`node:test`) covering happy paths, negative rejections, and security edge cases to ensure 100% test pass rates and prevent future regressions.
